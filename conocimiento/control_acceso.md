# Control de acceso y asistencia

## El lector biométrico no reconoce la huella
1. Limpia el sensor con un paño seco.
2. Pide a la persona secarse las manos y apoyar el dedo completo.
3. Prueba con otro dedo registrado.
4. Si falla de forma repetida, vuelve a registrar la huella con tres muestras.
5. Si le falla a todas las personas, revisa el sensor y escala el caso.

## La puerta no abre o no cierra
1. Por seguridad de las personas, confirma que exista una salida alterna disponible.
2. Revisa si el evento aparece como acceso concedido en el software.
3. Si el acceso fue concedido, el problema suele ser la cerradura o su fuente de energía.
4. Si fue denegado, revisa los permisos y el horario asignado a la persona.
5. Nunca desactives una cerradura de ruta de evacuación sin autorización del responsable del sitio.

## Marcaciones que no llegan al software de asistencia
1. Verifica que el dispositivo esté en línea y tenga la hora correcta.
2. Revisa la IP del dispositivo y la comunicación con el servidor.
3. Descarga las marcaciones manualmente desde el software o por memoria USB.
4. Confirma que la persona exista en el software con el mismo número de identificación.
5. Revisa que las reglas de horario estén asignadas antes de generar la prenómina.
